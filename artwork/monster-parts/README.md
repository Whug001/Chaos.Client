# Medenia monster part drops

Item icons for body-part drops from Medenia monsters. Each design comes from the monster's
sprite in `hades.dat` (`mns###.mpf`) and its template name under
`Unora/Data/Configuration/Templates/Monsters/Medenia/`.

Every file is a 32x32 PNG with a transparent background. The artwork itself sits between
16 and 21 pixels on its longest side, centered on the canvas.
